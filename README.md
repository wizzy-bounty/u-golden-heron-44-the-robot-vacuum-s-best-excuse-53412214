One line, at most 140 characters: the funniest excuse a robot vacuum gives
for missing a spot. A tired homeowner judges the entries head to head.

> My bumper tapped the chair leg 47 times. It never apologized, so I left its dust as a warning.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`.
